# PS网页版
使用h5实现的web版PS

# 使用
在线访问：<https://lxj5820.github.io/PS/>

# 说明
本项目源自稿定设计部署的在线 PS 页面（Photopea 内核，原地址 <https://ps.gaoding.com>），
源码由上游项目 [guobao2333/PS-Online](https://github.com/guobao2333/PS-Online) 整理发布。

本仓库在上游基础上做了以下修改：
- 移除账户/登录功能：顶栏"账户"入口、指向 `ps.gaoding.com/papi` 的登录监听与云同步心跳、手机端登录拦截脚本（`js/f.js`）
- 图层混合模式等界面汉化（正常、正片叠底、柔光、穿透 等 27 项）
- 移除广告脚本与友情链接挂件
